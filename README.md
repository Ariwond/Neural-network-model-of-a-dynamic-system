Описание проекта

В данном проекте реализована нейросетевая модель для аппроксимации динамики нелинейной системы дифференциальных уравнений.

Цель работы — обучить полносвязную нейронную сеть предсказывать несколько будущих состояний динамической системы по её текущему состоянию.

Для генерации обучающей выборки используются численные решения системы, полученные с помощью solve_ivp из библиотеки SciPy. После этого нейронная сеть обучается воспроизводить полученные траектории.
Математическая модель

Рассматривается нелинейная динамическая система:

$$ F(x1, x2) = \begin{cases} \dot{x}1 = 5x2 - 3x1^3, \ \dot{x}2 = -x1 - 2\sin(x2). \end{cases} $$

где:

    $x_1$ — первая координата состояния системы;
    $x_2$ — вторая координата состояния системы;
    $\dot{x}1$ и $\dot{x}2$ — производные координат по времени.

Начальные состояния системы случайным образом выбираются в диапазоне:

$$ x1, x2 \in [-1, 1]. $$
Параметры модели

В соответствии с условием задания используются следующие параметры:
Параметр	Значение
Шаг по времени $T$	0.01
Количество будущих моментов $N$	3
Количество скрытых слоёв $L$	3
Размер входного слоя	2
Размер скрытых слоёв	64
Размер выходного слоя	6
Функция активации	ReLU
Функция потерь	MSE
Оптимизатор	Adam
Learning rate	0.001
Количество эпох	200
Размер генерируемой выборки	2000

Функция активации:

$$ \phi(s) = \begin{cases} 0, & s < 0,\ s, & s \geq 0. \end{cases} $$

То есть используется ReLU (Rectified Linear Unit).
Архитектура нейронной сети

В качестве аппроксиматора динамической системы используется полносвязная нейронная сеть.

Структура модели:

Вход
  │
  ▼
Linear(2 → 64)
  │
 ReLU
  │
  ▼
Linear(64 → 64)
  │
 ReLU
  │
  ▼
Linear(64 → 64)
  │
 ReLU
  │
  ▼
Linear(64 → 6)
  │
  ▼
Выход

На вход сети подаётся текущее состояние системы:

$$ x(t) = [x1(t), x2(t)]. $$

На выходе сеть предсказывает состояния системы в следующие три момента времени:

$$ x(t+T), \quad x(t+2T), \quad x(t+3T). $$

Поскольку каждое состояние содержит две координаты, размер выходного вектора равен:

$$ 2 \cdot N = 2 \cdot 3 = 6. $$

Таким образом:

$$ [x1(t),x2(t)] \rightarrow [x1(t+T),x2(t+T),x1(t+2T),x2(t+2T),x1(t+3T),x2(t+3T)]. $$
Генерация обучающей выборки

Для получения обучающих данных используется численное решение исходной системы дифференциальных уравнений с помощью функции solve_ivp.

Для каждого примера:

    случайно генерируется начальное состояние $x(0)$;
    система решается на интервале от $0$ до $N \cdot T$;
    сохраняются состояния в моменты времени $T$, $2T$ и $3T$;
    начальное состояние используется как вход сети;
    полученные будущие состояния используются как целевая переменная.

Всего генерируется 2000 примеров.

Схематично процесс выглядит следующим образом:

Случайное начальное состояние
          │
          ▼
       x(0)
          │
          ▼
     solve_ivp
          │
          ▼
 ┌───────────────────────┐
 │ x(T)                  │
 │ x(2T)                 │
 │ x(3T)                 │
 └───────────────────────┘
          │
          ▼
   Обучающая выборка

Обучение

Для обучения используется функция потерь среднеквадратичной ошибки:

$$ MSE = \frac{1}{n}\sum{i=1}^{n}(yi-\hat{y}_i)^2. $$

В качестве оптимизатора используется Adam с коэффициентом обучения:

learning rate = 0.001

Обучение проводится в течение:

200 эпох

На каждой эпохе:

    вычисляется прогноз нейронной сети;
    рассчитывается значение MSE;
    выполняется обратное распространение ошибки;
    обновляются параметры сети.

График обучения

В процессе обучения сохраняется значение функции потерь на каждой эпохе.

Для визуализации используется логарифмическая шкала по оси $Y$:

plt.yscale('log')

Это позволяет лучше наблюдать уменьшение ошибки на разных этапах обучения.

По графику можно оценить сходимость модели и определить момент, когда дальнейшее обучение перестаёт существенно уменьшать ошибку.
Проверка модели

После завершения обучения модель переводится в режим оценки:

model.eval()

Для проверки генерируется новая случайная начальная точка:

$$ x(0) \in [-0.5, 0.5]^2. $$

Эта точка не использовалась при обучении модели.

Для неё двумя способами вычисляется дальнейшая динамика:

    истинная траектория — с помощью solve_ivp;
    предсказанная траектория — с помощью обученной нейронной сети.

После этого результаты сравниваются графически.
Визуализация результатов

Строятся три графика.
1. Динамика координаты $x_1$

Сравниваются:

    истинное значение $x_1(t)$;
    предсказание нейронной сети.

2. Динамика координаты $x_2$

Сравниваются:

    истинное значение $x_2(t)$;
    предсказание нейронной сети.

3. Фазовая траектория

Строится траектория системы на фазовой плоскости:

$$ (x1, x2). $$

На одном графике отображаются истинная и предсказанная траектории.
Результаты

После обучения нейронная сеть позволяет аппроксимировать динамику исходной нелинейной системы.

При сравнении истинных и предсказанных значений наблюдается близкое совпадение траекторий на рассматриваемом коротком временном интервале.

Небольшие различия между предсказанием и численным решением могут быть обусловлены ограниченным количеством точек прогнозирования и особенностями аппроксимации нелинейной динамики нейронной сетью.

Таким образом, обученная модель успешно воспроизводит поведение исходной динамической системы на тестовой начальной точке.
Используемые библиотеки

Проект реализован на Python с использованием следующих библиотек:

    PyTorch — создание и обучение нейронной сети;
    NumPy — работа с массивами и генерация случайных начальных состояний;
    SciPy — численное решение системы дифференциальных уравнений;
    Matplotlib — построение графиков и визуализация результатов.

Установка зависимостей

pip install torch numpy scipy matplotlib
